# WildGuard Explorer

A modern wildlife conservation website focused on Tanzania's iconic wildlife and ecosystems, built with HTML, CSS, and JavaScript.

## About

WildGuard Explorer uses AI-powered monitoring to protect Tanzania's wildlife and ecosystems through technology, education, and community action.

## Features

- **Wildlife Library** — Explore Tanzania's Big Five and other species with detailed information
- **National Parks** — Learn about Serengeti, Ngorongoro, Tarangire, and other protected areas
- **Scan Mode** — Simulated real-time wildlife detection interface
- **Conservation Efforts** — Discover anti-poaching, community engagement, and habitat preservation initiatives
- **Get Involved** — Donate, adopt animals, and participate in educational programs
- **Responsive Design** — Works on desktop, tablet, and mobile devices

## Tech Stack

- HTML5 & CSS3 (with CSS variables and glassmorphism)
- Vanilla JavaScript (ES6+)
- Flask (Python backend)
- Node.js/Express (API)
- Font Awesome icons
- Google Fonts

## Pages

- `index.html` — Home page with hero slideshow, wildlife cards, parks, conservation, and get involved sections
- `library/mammals.html` — Mammal species library (birds, reptiles, amphibians, aquatic, plants, fungi, bacteria pages also exist)
- `scan.html` — Real-time wildlife scan simulation
- `about.html` — Mission, vision, and impact
- `contact.html` — Contact form and field team information
- `admin/` — Admin dashboard, upload, and animal management pages
- `user/` — User profile, history, and favorites pages

## Development

The site is currently a frontend demo with mock data. Backend API endpoints are defined but not connected to a live database.

## Deployment

The site is configured for GitHub Pages deployment via `.github/workflows/deploy.yml`.
