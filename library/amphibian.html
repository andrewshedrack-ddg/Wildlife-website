Amphibians

Frogs and toads adapted to varied habitats from rainforests to deserts.

Amphibians of East Africa

Remarkable adaptations from rainforest streams to seasonal savanna pools.

African Bullfrog

Least Concern

Scientific Name: Pyxicephalus adspersus

Weight Range: 1.5 - 3.3 lbs (0.7 - 1.5 kg)

Key Detail: One of Africa's largest frogs; males guard tadpoles and dig channels to connect pools.

Red-eyed Tree Frog

Least Concern

Scientific Name: Leptopelis vermiculatus

Weight Range: 0.2 - 0.4 oz (6 - 12 g)

Key Detail: Striking red eyes and bright green body; nocturnal canopy dweller in Eastern Arc Mountains.

African Clawed Frog

Least Concern

Scientific Name: Xenopus laevis

Weight Range: 2 - 8 oz (60 - 230 g)

Key Detail: Fully aquatic with clawed hind feet; used worldwide in pregnancy tests historically.

Painted Reed Frog

Least Concern

Scientific Name: Hyperolius marmoratus

Weight Range: 0.1 - 0.2 oz (3 - 6 g)

Key Detail: Incredibly variable colors and patterns; males call from reeds at night with distinctive trills.

Bubbling Kassina

Least Concern

Scientific Name: Kassina senegalensis

Weight Range: 0.3 - 0.5 oz (8 - 15 g)

Key Detail: Distinctive bubbling call like water droplets; runs rather than hops across savanna.

Angola River Frog

Least Concern

Scientific Name: Amietia angolensis

Weight Range: 0.5 - 1.5 oz (15 - 45 g)

Key Detail: Fast-flowing stream specialist; tadpoles have large oral suckers to cling to rocks.

Common African Toad

Least Concern

Scientific Name: Sclerophrys regularis

Weight Range: 1 - 3 oz (30 - 85 g)

Key Detail: Widespread across savannas; parotoid glands secrete bufotoxins for defense.

Natal Puddle Frog

Least Concern

Scientific Name: Phrynobatrachus natalensis

Weight Range: 0.05 - 0.1 oz (1.5 - 3 g)

Key Detail: Tiny frog breeding in temporary puddles; explosive breeders after rains.

Clicking Stream Frog

Least Concern

Scientific Name: Strongylopus grayii

Weight Range: 0.1 - 0.3 oz (3 - 8 g)

Key Detail: Distinctive clicking call like pebbles struck together; endemic to eastern and southern Africa.

Waterlily Reed Frog

Least Concern

Scientific Name: Hyperolius pusillus

Weight Range: 0.05 - 0.1 oz (1.5 - 3 g)

Key Detail: Translucent green skin; spends days sleeping on waterlily leaves, nights calling.

Mascarene Grass Frog

Least Concern

Scientific Name: Ptychadena mascareniensis

Weight Range: 0.3 - 0.7 oz (8 - 20 g)

Key Detail: Long-legged jumper of open grasslands; explosive leaps escape predators.

Greater Leaf-folding Frog

Least Concern

Scientific Name: Afrixalus fornasinii

Weight Range: 0.1 - 0.2 oz (3 - 6 g)

Key Detail: Females fold leaves with silk to create nest chambers for eggs above water.
